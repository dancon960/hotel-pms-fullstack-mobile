# Hotel PMS - Mobile Version

Aplicación móvil nativa para la gestión de servicios hoteleros. Este proyecto forma parte del ecosistema Fullstack y se centra en la gestión operativa (incidencias, limpieza y control de habitaciones).

## 🚀 Tecnologías
* **React Native** con **Expo**
* **TypeScript**
* **Expo Router** (Navegación basada en archivos)
* **Zustand** (Gestión de estado global)
* **FlashList** (Renderizado de alto rendimiento)
