# Definición de la Idea: Hotel PMS Mobile

## 1. Problema que resuelve
La gestión de un hotel requiere movilidad. El staff (recepción, limpieza y mantenimiento) no puede depender de una web de escritorio para registrar incidencias o marcar tareas completadas en tiempo real. Esta app permite una gestión operativa ágil desde cualquier lugar del hotel.

## 2. Usuario objetivo
Staff operativo del hotel:
- **Recepcionistas:** Para apuntar notas rápidas sobre huéspedes.
- **Personal de limpieza (Housekeeping):** Para gestionar el estado de las habitaciones.
- **Mantenimiento:** Para visualizar y cerrar incidencias técnicas.

## 3. Funcionalidades principales (MVP)
- **Gestión de Incidencias (Notas):** Registro de texto libre sobre problemas en habitaciones o áreas comunes.
- **Checklists de Limpieza (Tareas):** Listado de puntos de control por habitación con barra de progreso.
- **Categorización de Habitaciones (Ideas):** Clasificación visual por etiquetas (VIP, Mantenimiento, Prioridad) y colores.
- **Persistencia Local:** Los datos se guardan en el dispositivo para consulta inmediata.

## 4. Funcionalidades opcionales (Futuro)
- Sincronización con el Backend en AWS.
- Notificaciones push para nuevas incidencias urgentes.
- Escaneo de códigos QR en puertas para abrir el checklist de esa habitación automáticamente.
